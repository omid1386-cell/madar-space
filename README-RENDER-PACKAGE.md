# مدار — بستهٔ کامل انتشار در رندر

این بسته برای بارگذاری در یک مخزن تازهٔ گیت‌هاب و اجرای کامل برنامه در رندر آماده شده است.

نسخهٔ بسته:

```text
0.9.1
```

راهنمای گام‌به‌گام:

```text
GITHUB-TO-RENDER-FA.md
```

فایل‌های اصلی کارساز:

```text
app.py
render.yaml
requirements.txt
Procfile
.python-version
```

تمام فایل‌های رابط در پوشهٔ زیر قرار دارند:

```text
public/
```

برای انتشار، خود فایل فشرده را در گیت‌هاب بارگذاری نکنید. بسته را استخراج کنید و محتویات داخل پوشهٔ استخراج‌شده را در ریشهٔ مخزن قرار دهید.

ساختار ضروری:

```text
repository-root/
├── app.py
├── render.yaml
├── requirements.txt
└── public/
    └── index.html
```

هیچ کلید، گذرواژه یا متغیر محرمانه‌ای برای اجرای این نسخه لازم نیست.
