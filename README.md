# مدار — آکادمی و رصدخانه فضایی

وب‌اپ فارسیِ واکنش‌گرا برای آموزش مهندسی فضا و مرور پژوهشی پرتاب‌ها، مدارها، پرتابگرها و شکست‌ها.

## قابلیت‌های نسخه 0.18 آزمایشی

- فاز نهایی مسیر تخصصی مکانیک مداری: فصل هجدهم تعیین مدار، حل‌گر صفر‌دور Lambert، انرژی Patched Conics، پانزده آزمایشگاه، پروژه جامع مأموریت و آزمون هجده‌پرسشی با حد نصاب و پیشرفت ذخیره‌شونده
- فاز چهارم توسعه تخصصی مکانیک مداری: اغتشاشات J2/Drag/SRP، طراحی SSO و مدارهای ویژه، حساسیت عمر و دفع، داده‌های TLE/SGP4 و عدم‌قطعیت همراه با چهار آزمایشگاه تخصصی
- فاز سوم توسعه تخصصی مکانیک مداری: فصل‌های رد زمینی، انتخاب مدار، مانور ضربه‌ای، انتقال هوهمن و دو-بیضوی، تغییر صفحه و فازبندی، حرکت نسبی و ملاقات مداری همراه با چهار آزمایشگاه محاسباتی
- فاز دوم توسعه تخصصی مکانیک مداری: هفت فصل پایه، آزمایشگاه تبدیل State Vector و عناصر مداری، حل‌گر بیضوی و هذلولی Kepler’s Equation، آزمون بازگشت و اعتبارسنجی عددی
- فاز صفر و فاز اول توسعه تخصصی مکانیک مداری: نسخه پایدار پشتیبان‌گیری شده، مسیر آزمایشی مستقل، ساختار پیشرفته فصل، نمونه کامل مسئله دو جسم، تمرین عددی و پیوند آزمایشگاه
- کارت‌های قابل‌کلیک NASA/ESA با صفحه جزئیات داخلی، ترجمه فارسی، متن رسمی انگلیسی، گزیده ساخت‌یافته، نکات کلیدی و پیوند مستقیم منبع
- حالت روز و شب کامل با فایل‌های واقعی نسخه‌دار، مهاجرت یک‌باره کش قدیمی، کنترل مستقل، تشخیص تنظیم دستگاه، ذخیره انتخاب کاربر و طراحی روشن همه بخش‌ها
- خلاصه‌ساز ویدئو با تشخیص دقیق محدودیت IP یوتیوب، مسیر تضمینی ورود متن زیرنویس، ترجمه کامل فارسی و تیک نمایش خلاصه و متن کامل انگلیسی
- کالبدشکافی پرتاب در ۱۰ مرحله با تصاویر اعتبارسنجی‌شده، fallback محلی و توضیح عمیق فیزیک، توالی، سامانه، تله‌متری، معیار موفقیت و شکست
- اطلس مدار توسعه‌یافته با محیط، اغتشاش، مخابرات، دسترسی، نگهداری، دفع، Checklist و نقشه طبقه‌بندی مدارها
- پیوند انگلیسی برای تمام اصطلاحات فنی و صفحه مستقل برای هرکدام، همراه معادل فارسی، تعریف ساده/دانشگاهی، مثال و کاربردها
- پنل پیش‌نیاز علمی و واژه‌های ضروری در درس، پرتاب، مدار، دانشنامه ماهواره و کتابخانه دانش
- کتابخانه دانش سه‌سطحی شامل ۷۵ موضوع: ۵ حوزه × ۳ سطح × ۵ درس، با پیش‌نیاز، رابطه، مثال و منبع

- مطالعه‌گر تمام‌صفحه با فهرست فصل، واژه‌نامه دوزبانه و ذخیره پیشرفت

## اجرا

نیازمند Python 3.10 یا جدیدتر:

```bash
cd madar
python -m pip install -r requirements.txt
python app.py
```

سپس `http://localhost:8000` را باز کنید. برای تغییر پورت:

```bash
PORT=9000 python app.py
```

## منابع داده

- Launch Library 2 (The Space Devs): رکوردها و وضعیت پرتاب
- CelesTrak GP/OMM: عناصر میانگین مداری
- GCAT (J. McDowell): مسیر توسعه تاریخچه بلندمدت و کاتالوگ اشیا
- NASA / ESA / JAXA / ISRO / FAA: آموزش و گزارش‌های رسمی

زمان واکشی داده زنده در رابط نمایش داده می‌شود. پاسخ‌های upstream برای پنج دقیقه cache و آخرین پاسخ معتبر روی دیسک نگه‌داری می‌شود تا محدودیت موقت API، رابط را خالی نکند.

## محدودیت‌های مهم

1. «شکست پرتاب»، «شکست بازیابی» و «حادثه آزمون زمینی» یکسان نیستند؛ رابط آن‌ها را جدا می‌کند.
2. علت پرونده‌های باز قطعی تلقی نمی‌شود. برای تصمیم فنی، گزارش نهایی مرجع رسمی لازم است.
3. محاسبه‌گرها مدل دو جسم/ایده‌آل‌اند و جای STK/GMAT/Orekit، تحلیل اغتشاشات یا طراحی trajectory را نمی‌گیرند.
4. دریافت کپشن YouTube به عمومی‌بودن ویدئو، وجود کپشن و محدودنبودن IP بستگی دارد. ترجمه رایگان از سرویس عمومی استفاده می‌کند و ممکن است موقتاً در دسترس نباشد.
5. ظرفیت پرتابگر تابع مدار، میل، پایگاه، نسخه وسیله و بازیابی است؛ اعداد کارت‌ها صرفاً مرجع مقایسه مقدماتی‌اند.

## گام‌های بعدی پیشنهادی

- ورود pipeline کامل GCAT و جست‌وجوی همه رکوردهای تاریخی
- پایگاه داده PostgreSQL و job زمان‌بندی‌شده برای ثبت نسخه داده
- صفحه مستقل برای هر مأموریت، ماهواره، پرتابگر، موتور و پایگاه
- افزودن نمودار reliability با تفکیک خانواده/نسخه پرتابگر
- موتور خلاصه‌سازی مبتنی بر مدل زبانی با استناد زمانی به transcript
- حساب کاربری، آزمون، فلش‌کارت و برنامه مطالعه تطبیقی
- شبیه‌ساز SGP4، ground track و پنجره تماس ایستگاه زمینی

## نام و هدف

«مدار» در این نسخه یک MVP پژوهشی/آموزشی است. هدف آن جایگزینی منبع اصلی نیست؛ هدف، تبدیل داده و منابع پراکنده به یک مسیر منسجم، قابل جست‌وجو و قابل پیگیری است.
